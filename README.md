# Fall 2026 Precalculus

Instructor: [Yi Zhu](https://sites.google.com/site/yizhuhomepage/home)

Class Schedule: To be announced

招收对象：对数学感兴趣的学生

课程介绍：本课程将系统介绍预备微积分中的核心概念与方法，包括函数及其图像、多项式与有理函数、指数与对数函数、三角函数、数列等内容。课程将结合专题讲解、例题分析和课堂互动讨论，帮助学生建立扎实的微积分预备基础，提高数学推理和解决问题的能力，并为后续学习微积分做好准备。本课程不要求学生在此前修读过相关内容。

Course Information: This course provides a systematic introduction to the core ideas and methods of precalculus, including functions and their graphs, polynomial and rational functions, exponential and logarithmic functions, trigonometry, and sequences. Lectures, worked examples, and interactive class discussions will help students build a solid foundation in precalculus, develop mathematical reasoning and problem-solving skills, and prepare for a future calculus course. Prior enrollment in this course is not required.
